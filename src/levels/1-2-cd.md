Print the summary report for the third quarter of 2024.

Everything old is in `archive/`, sorted by year and then by quarter (`q1` to `q4`). The one you want is `summary.txt` in that quarter's `reports` folder.

+++ setup
RANDOM=$((VARIANT + 11))
pages=(/ /blog /pricing /docs /about)
for y in 2023 2024 2025; do
  for q in q1 q2 q3 q4; do
    mkdir -p "archive/$y/$q/reports" "archive/$y/$q/drafts"
    printf 'Summary for %s %s\nVisitors: %d\nTop page: %s\n' "${q^^}" "$y" $((RANDOM % 9000 + 1000)) "${pages[RANDOM % 5]}" \
      > "archive/$y/$q/reports/summary.txt"
    echo "Draft, not final. See reports/ for the real numbers." > "archive/$y/$q/drafts/summary.txt"
  done
done
echo "Replaced by summary.txt" > archive/2024/q3/reports/summary-old.txt

+++ solution
cat archive/2024/q3/reports/summary.txt

+++ tools
- `ls`: lists what's in a directory. `ls archive` lists `archive/` without going there.
- `cd`: changes directory. `cd ..` goes back up one.
- `pwd`: prints where you are.

Press <kbd>Tab</kbd> while typing a name and the shell finishes it for you. Press it twice to see the choices.

+++ steps
Look inside the archive: `ls archive`

---
Go in, one level at a time: `cd archive/2024`, then `ls`.

Type `cd ar` and press <kbd>Tab</kbd>: the shell fills in `archive/`.

---
Keep going: `cd q3/reports`, then `pwd` to see where you've ended up.

---
Print it: `cat summary.txt`, then press **Check**. The check reruns your command from the directory you're in.

+++ debrief
**You didn't have to `cd` at all.** From `~/work`, `cat archive/2024/q3/reports/summary.txt` does the same in one go. A path can go through as many directories as it needs, and <kbd>Tab</kbd> makes typing a long one quick.

**Relative and absolute paths**

- `archive/2024` is *relative*: it starts from where you are.
- `/home/player/work/archive/2024` is *absolute*: it starts with `/`, so it works from anywhere.
- `~` is short for your home directory, so `~/work` works from anywhere too.

**Getting around**

- `cd ..` goes up one level, and `cd ../..` goes up two.
- `cd -` jumps back to the directory you were in before.
- `cd` on its own takes you home.
- `tree archive` draws the whole layout at once.

**A gotcha.** Tab completion only finishes a name when there's one match. If nothing happens, press <kbd>Tab</kbd> again to see the choices: here, `summary-old.txt` and `summary.txt` both start with `summary`.

+++ sheet
```bash
pwd               # where am I?
cd archive/2024   # go in (relative to here)
cd ..             # up one level
cd -              # back to where you just were
cd                # home (same as cd ~)
ls archive/2024   # look without going there
```

+++ tip
Press <kbd>Tab</kbd> to complete a name, and twice to see the choices.
