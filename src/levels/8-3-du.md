The disk is nearly full. Find out what's using the space: list **every directory here with its size**, **biggest last**, the way `du -sh` prints them:

```
16K	notes
304K	cache
...
```

+++ setup
sizes=(16 120 300 640 1100)
[ "$VARIANT" = 1 ] && sizes=(1100 16 640 120 300)
i=0
for d in notes music photos cache videos; do
  mkdir -p "$d/old"
  head -c $(( sizes[i] * 1024 / 2 )) /dev/zero > "$d/a.bin"
  head -c $(( sizes[i] * 1024 / 2 )) /dev/zero > "$d/old/b.bin"
  i=$((i + 1))
done

+++ solution
du -sh * | sort -h

+++ tools
- `du`: how much disk space files and directories use. `-s` gives one total per argument, and `-h` makes it readable, like `1.5M`
- `sort -h` sorts those readable sizes properly

`ls -l` won't help with directories: it shows the size of the directory entry itself, not what's in it.

+++ steps
Try `ls -lh` first. The sizes it shows for directories are tiny, nothing like what's inside them.

---
`du` adds up everything inside. `-s` gives one line per directory and `-h` makes the numbers readable:

`du -sh *`

---
Sort them. `sort -n` would put `900K` after `2.2M`, because it only sees the numbers. `sort -h` understands `K`, `M` and `G`:

`du -sh * | sort -h`

Press **Check**.

+++ debrief
**Biggest last, on purpose.** With the biggest at the bottom, the answer is right above your prompt even when the list is long. `sort -rh | head` gives the top ten instead.

**Going deeper.** Once you know `videos` is the big one, run it again inside: `du -sh videos/* | sort -h`. `du -h --max-depth=2` shows two levels at once.

**What `du -sh *` misses.** `*` skips hidden directories, and those are often where space goes: `.cache`, `.local`. `du -sh .[!.]* * | sort -h` includes them.

**Whole disks.** `df -h` shows how full each disk is. `du` tells you what's using it.

**Files too.** `du -sh *` lists files alongside directories. `du -sh */` lists only directories, with a `/` on each name.

+++ sheet
```bash
du -sh * | sort -h     # what's big here, biggest last
du -sh dir             # one directory's total
du -h --max-depth=2    # two levels down
df -h                  # how full each disk is
ls -lhS                # files by size, biggest first
```

+++ tip
`ls -l` shows a directory as a few K whatever it holds. `du -sh` adds up what's inside.
