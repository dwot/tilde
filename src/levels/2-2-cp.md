title: Back it up first
---
Before you change anything, make backups:

- a copy of `config.yml` called `config.yml.bak`
- a copy of the whole `site/` directory, called `site-backup/`

Leave the originals where they are.

+++ setup
printf 'title: My site\ntheme: calm\nport: 8080\n' > config.yml
mkdir -p site/css site/images
echo '<h1>Hello</h1>' > site/index.html
echo 'body { font-family: serif; }' > site/css/style.css
echo 'not really a png' > site/images/logo.png

+++ check
fail=0
[ -f config.yml ] || { echo "config.yml has gone: it should stay where it is"; fail=1; }
if [ ! -f config.yml.bak ]; then echo "config.yml.bak is missing"; fail=1
elif ! cmp -s config.yml config.yml.bak; then echo "config.yml.bak isn't the same as config.yml"; fail=1; fi
[ -d site ] || { echo "site/ has gone: it should stay where it is"; fail=1; }
if [ -d site-backup/site ]; then
  echo "site-backup/site/ exists: site was copied into an existing site-backup/, one level too deep"; fail=1
elif [ ! -d site-backup ]; then echo "site-backup/ is missing"; fail=1
else
  for f in index.html css/style.css images/logo.png; do
    cmp -s "site/$f" "site-backup/$f" 2>/dev/null || { echo "site-backup/$f is missing or different"; fail=1; }
  done
fi
exit $fail

+++ solution
cp config.yml config.yml.bak
cp -r site site-backup

+++ tools
- `cp`: copies a file. `cp from to`, in that order.
- `cp -r`: copies a directory and everything in it (`-r` is for *recursive*)

Try `man cp`.

+++ steps
Copy the file: `cp config.yml config.yml.bak`

---
Copy the directory: `cp -r site site-backup`

Without `-r`, `cp` skips directories and says so.

---
Make sure both are there: `ls`, then `tree site-backup`. Press **Check**.

+++ debrief
**Where the copy lands depends on whether the target exists.** `site-backup/` didn't exist, so `cp -r site site-backup` made it as a copy of `site/`. If `site-backup/` had already existed, the same command would have put the copy *inside* it, as `site-backup/site/`. Run it twice and you'll see.

**A brace shortcut.** `cp config.yml{,.bak}` expands to `cp config.yml config.yml.bak`: the braces hold an empty choice and `.bak`.

**Options worth knowing**

- `cp -i`: ask before overwriting a file that's already there
- `cp -a`: like `-r`, but also keeps dates and permissions. Better for real backups.
- `cp -v`: print each file as it's copied
- `cp *.txt notes/`: copy many files into a directory, like `mv`

+++ sheet
```bash
cp a.txt b.txt          # copy a file
cp -r site site-backup  # copy a whole directory
cp -a site site-backup  # ...keeping dates and permissions
cp config.yml{,.bak}    # = cp config.yml config.yml.bak
cp *.txt notes/         # copy many into a directory
```

+++ tip
If the target directory already exists, `cp -r` puts the copy inside it.
