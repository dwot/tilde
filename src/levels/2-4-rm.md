`essay/` is full of clutter. Clear it out:

- delete `draft1.txt` to `draft9.txt`, but **keep** `draft12.txt` and `draft-final.txt`
- delete the empty directory `old/`
- delete the `scratch/` directory and everything in it

+++ setup
mkdir -p essay/old essay/scratch/ideas
for i in 1 2 3 4 5 6 7 8 9 12; do echo "Draft $i" > "essay/draft$i.txt"; done
echo "The finished essay." > essay/draft-final.txt
echo "Sources I used." > essay/sources.txt
echo "half an idea" > essay/scratch/ideas/one.txt
echo "another" > essay/scratch/notes.txt

+++ check
fail=0
for i in 1 2 3 4 5 6 7 8 9; do
  [ -e "essay/draft$i.txt" ] && { echo "essay/draft$i.txt is still there"; fail=1; }
done
for f in draft12.txt draft-final.txt sources.txt; do
  [ -f "essay/$f" ] || { echo "essay/$f was deleted, but it should stay"; fail=1; }
done
[ -e essay/old ] && { echo "essay/old/ is still there"; fail=1; }
[ -e essay/scratch ] && { echo "essay/scratch/ is still there"; fail=1; }
exit $fail

+++ solution
rm essay/draft?.txt
rmdir essay/old
rm -r essay/scratch

+++ tools
- `rm`: deletes files. There's no bin to get them back from.
- `rmdir`: deletes a directory, only if it's empty
- `rm -r`: deletes a directory and everything in it
- `?` in a name matches exactly **one** character, where `*` matches any number

Put `echo` in front of an `rm` to see what it would delete.

+++ steps
`cd essay`, then preview: `echo draft?.txt`

`?` stands for one character, so it matches `draft1.txt` to `draft9.txt` but not `draft12.txt` (two characters) or `draft-final.txt`.

---
When the list looks right: `rm draft?.txt`

---
The empty one: `rmdir old`

---
The one with things inside: `rm -r scratch`. Then `ls` and press **Check**.

+++ debrief
**Why not `draft*.txt`?** `*` matches any number of characters, including `-final` and `12`, so it would have deleted the two drafts you wanted. `echo draft*.txt` shows that before it's too late.

**Other ways to say it**

- `rm draft[1-9].txt`: square brackets match one character from a set or range
- `rm draft{1..9}.txt`: brace expansion writes out all nine names. Unlike a wildcard, it doesn't check they exist, so `rm` would complain about any that are missing.

**`rmdir` is the careful one.** It refuses to delete a directory that still has something in it, so you can't lose files by accident. `rm -r` deletes everything without asking.

**Options worth knowing**

- `rm -i`: ask before each file
- `rm -v`: print each file as it goes
- `rm -rf`: `-f` means don't ask and don't complain. Read the command twice before pressing <kbd>Enter</kbd>.

+++ sheet
```bash
rm notes.txt          # delete a file (no undo!)
rm draft?.txt         # ? matches exactly one character
rm draft[1-9].txt     # [...] matches one from a set
rmdir old             # delete an empty directory
rm -r scratch         # delete a directory and contents
echo draft?.txt       # preview what a pattern matches
```

+++ tip
Before any `rm` with a wildcard, run it with `echo` in front first.
